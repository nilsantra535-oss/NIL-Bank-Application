# 💖 NIL Bank Application

A sleek, interactive Streamlit-based web application combined with a CLI-based backend for basic banking operations. Features account creation, money deposit/withdrawal, details updating, and account closure with a modern glassmorphism aesthetic.

---

## ✨ Features

- **🏠 Interactive Dashboard**: View total accounts, aggregate balance, and account metrics.
- **✨ Account Creation**: Register as a new user with real-time field validation (age limit, 10-digit phone number, 4-digit PIN).
- **🔐 User Authentication**: PIN-based login system for safe account operations.
- **💸 Deposit & 🏧 Withdraw**: Seamless virtual money operations with automatic balance updates.
- **🪪 Account Details**: View your profile details and live balance.
- **✏️ Profile Update**: Update name, email, phone number, or PIN easily.
- **🗑️ Close Account**: Securely deactivate and remove user data.
- **💾 Local Persistence**: All data is automatically saved to a local `database.json` file.

---

## 🛠️ Tech Stack

- **Frontend**: Streamlit, HTML5, Custom CSS3 (Glassmorphism & CSS Animations)
- **Backend**: Python 3.x
- **Data Persistence**: JSON File Storage (`database.json`)
